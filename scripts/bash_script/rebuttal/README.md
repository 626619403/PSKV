# Supplementary Batch Scripts

This directory contains the batch scripts used for supplementary and rebuttal experiments:

- `multi_seed_asr.sh`, `multi_seed_2.sh`, and `multi_seed_3.sh` submit repeated ASR runs.
- `multi_seed_advprompter.sh` submits AdvPrompter repeated runs.
- `memory_profile.sh`, `long_context.sh`, and `nsys_memory_profile.sh` run memory profiling.
- `collect_multi_seed_results.py` summarizes repeated ASR logs.
- `repeated_asr/` contains packed HarmBench seed-1/seed-2 ASR jobs.

Run these scripts from the repository root unless a script states otherwise.
